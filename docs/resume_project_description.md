# 简历项目描述

## 项目名称

Arknights Analytics｜《明日方舟》IP周边选品与商品运营分析平台｜个人数据分析项目

## 技术栈

Python / Pandas / NumPy / SQL / SQLite / Excel / Matplotlib / pytest / Requests / BeautifulSoup

## 推荐简历版本

- **业务目标：**针对ACG周边选品依赖经验、内容热度难转化为购买判断及库存风险缺少量化依据的问题，构建“社媒热度—用户调研—淘宝商业信号—候选试点—ERP经营分析”链路，为角色选取、品类规划、内容预热、供应商比价、价格带、补货和滞销处理提供数据支持。
- **数据分析：**整合549条B站官号历史内容、271条角色Campaign关联、100条微博官号内容、4期小红书品牌生态快照和84条淘宝公开商品快照；使用Python/Pandas完成角色实体归因、发布时间归一化及跨平台热度评分，并通过SQLite中的JOIN、CTE、Window Function与CASE WHEN形成内容商业矩阵和经营决策队列。
- **用户调研：**独立设计并回收243份匿名正版周边问卷，拆分729条角色Top-3排序与1,701条七品类价格观测；使用分群、加权排序和交叉分析识别用户预算、购买渠道、价格接受度及主要阻力，18～22岁样本占72.02%，角色偏好前三为德克萨斯、维什戴尔和史尔特尔。
- **ERP处理：**围绕SKU、订单、库存、采购、售后和财务构建7张模拟业务表，生成210个SKU、6,000张订单、7,652条订单明细、18,900条库存日快照、355张采购单和392条售后记录；计算Gross Margin、Return Rate、Sell-through Rate、Inventory Turnover、Days of Inventory与Reorder Point，输出补货、高退货和库存风险队列。
- **试点设计：**基于公开聚合数据与真实匿名问卷形成210个角色×品类候选组合，建立覆盖候选审批、内容预热、匿名意向、供应商报价、订单、履约、售后和评价的真实业务数据契约；通过授权证据、知情同意、金额对账和七阶段门禁阻止不完整数据进入经营结论。
- **工程质量：**建立18个业务视图、43组分析SQL和29个索引，通过订单头明细对账、库存平衡、数据边界与数据库导出测试保证结果可复核；累计完成70项pytest自动化测试，代码覆盖率达到82%。

## 一句话介绍

我将公开内容热度、243份匿名用户调研与淘宝商品信号连接到候选试点和模拟ERP经营链路，用Python/SQL完成角色选品、价格、渠道、供应商、库存周转、补货和售后分析，并通过70项自动化测试保证数据结果可复核；真实商业试点结果必须由实际记录触发，不使用模拟数据代替。

## 真实性口径

- 243份问卷经批次所有者确认为真实匿名回收，但属于便利抽样，不代表全部玩家。
- B站、微博、小红书和淘宝数据属于采集时点公开快照；淘宝收货人数按公开下界代理处理。
- ERP订单、库存、采购、售后、收入与毛利均为模拟数据，只用于展示分析方法，不可表述为企业真实经营业绩。
