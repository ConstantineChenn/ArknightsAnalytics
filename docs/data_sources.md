## 用户调研：243份答卷

243份匿名答卷经项目维护者确认属于真实回收，源TXT标题曾误标为模拟数据。该批次采用便利抽样，原始导出没有提交时间和填写时长；不补造这两个字段，也不把样本结论外推为全体玩家的需求比例。

| 单位 | 数量 | 含义 |
| --- | --- | --- |
| 匿名答卷 | 243份 | 受访样本基数 |
| 角色排名 | 729条 | 每份答卷的Top-3角色选择展开 |
| 品类与价格观察 | 1,701条 | 每份答卷的7类品类回答展开 |

三项不能相加作为受访人数。购买意愿与购买阻力用于发现待验证需求，不是支付转化率。另有明确标注的模拟问卷演示数据，存储和报告均与该真实批次区分。问卷设计与解释规则见[用户调研协议](user_research_protocol.md)。

## 商品档案：公开链接与内部SKU

既有商品维护层含19项字段规范、83个公开商品档案和210个模拟内部SKU。公开商品链接可能包含多个角色、规格或付款阶段，不能与内部SKU一一等同。

页面“官方/授权”自述、搜索词命中、标题角色与人工核验证据分别保存。基线中13条带官方/授权标签的快照对应12个独立链接；标签只用于有条件的观察筛选，**不构成项目对授权有效性的认证**。商品信息的维护、版本覆盖和审计见[工作台使用指南](platform_guide.md)。

### 历史退款问题与修正重建

历史快照包含44笔退款超实付异常和1项采购逾期提醒。退款生成逻辑修正后，验证脚本以相同输入、90天周期、6,000张订单及随机种子20260903重建，在订单等其余字段保持一致的前提下，44项数据异常降为0；采购提醒仍保留。

修正涉及149条售后记录的退款金额，**149是金额变化记录数，44是触发异常的订单数**。差额属于模拟数据口径修正，不是追回款项。历史CSV刻意保留用于复核，因此默认看板仍读取旧金额；独立验证不会自动刷新看板或其他报告。复现见[ERP核对与修正流程](erp_checks_workflow.md)。

## 经营指标与方案假设

| 指标或分析 | 定义与限制 |
| --- | --- |
| 支付商品GMV | 已支付商品金额扣除优惠，不含运费，退款另列；不能与含运费实收混用 |
| 订单支付完成率 | 支付订单数 / 创建订单数；没有访问量时不能称为访客转化率 |
| 支付客单价（AOV） | 支付商品GMV / 支付订单数，分子分母使用同一范围 |
| 营销贡献利润 | 按方案约定纳入折扣、退款、商品、履约与推广成本；属于情景测算，非财务审计净利润 |
| 库存建议 | 结合可售库存、销售速度及采购交期形成待复核建议，历史销售不保证未来销量 |
| 复购与LTV | 客户级历史不足时保留缺失，不从角色偏好或模拟渠道分布反推 |

4类营销方案的12组假设用于检验对转化、折扣和成本的敏感程度，不表示已运行12次线上实验。7类模拟订单渠道与7类规划渠道是不同分类，后者包含众筹、零售代理等方案；1,470组SKU与渠道适配记录不代表接入或运营了1,470条销售链路。

详见[GMV驱动分析](gmv_drivers.md)、[渠道策略](channel_strategy.md)与[商业数据决策](business_decisions.md)。

## 选品稳定性与角色生命周期

60名角色的209组权重扰动与去源实验产生12,540条排名观测，回答的是“候选排序是否对分析条件敏感”。它不是独立受访样本，也不能证明角色处于某个生命周期阶段。

生命周期模块单独整理直接内容、宣传事件、28日窗口与观察依据。当前报告中，没有角色满足连续需求趋势判断所需的证据条件，因此保留“待验证”“证据不足”或事件观察状态。方法见[角色生命周期观察](character_lifecycle.md)。
